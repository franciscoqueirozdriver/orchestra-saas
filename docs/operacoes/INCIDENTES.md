| | | | | | | | |

## Regras

- Registrar apenas incidentes realmente observados ou confirmados.
- Não incluir dados sensíveis (`.env`, credenciais, payloads reais, transcrições).
- Associar ao SHA do commit onde a correção foi aplicada, quando houver.
- Isso evita que um erro antigo seja investigado de novo como se fosse novo.
